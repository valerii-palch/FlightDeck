# FlightDeck для Windows

Приложение использует общий интерфейс и облачный журнал FlightDeck. Установщик для Windows 10/11 включает Chromium и выбирает сборку x64 или ARM64 автоматически.

## Сборка

На Windows нужны Node.js 24 с npm, Python 3 (команда `python`) и интернет для загрузки зависимостей. Открой PowerShell или командную строку в `FlightDeck-Windows` внутри общей рабочей копии.

```powershell
npm install
npm run build
```

В `dist` появится `FlightDeck-0.22.1-Windows-Setup.exe`. Распакованное приложение с `FlightDeck.exe` и сопутствующими файлами находится в каталогах `win-unpacked` и `win-arm64-unpacked`. Для разработки можно запустить `npm start`.

## Установка и данные

Запусти установщик и выбери папку. Установщик создаёт ярлыки на рабочем столе и в меню «Пуск». Сборка по умолчанию без цифровой подписи издателя.

В «Профиле» войди с теми же данными, что и на других устройствах. Для переноса журнала из браузера можно также экспортировать JSON через «Резервная копия» и загрузить его в приложении. Импорт заменяет текущий локальный журнал. У установленного приложения свой каталог данных, который сохраняется при обновлении и удалении через установщик.

Вход Google и подключение статистики реальных рейсов описаны в `../SETUP-0.19.md`.
