# FlightDeck — вход Google и оценка длительности

## Вход через Google

В приложениях macOS и Windows добавлена кнопка «Продолжить с Google» в профиле. Вход открывается в системном браузере. Приложение обменивает одноразовый код на сеанс Supabase с проверкой PKCE.

Для включения входа нужны настройки владельца проекта.

1. В Google Cloud → Google Auth Platform создай OAuth Client типа Web application. Настрой Audience, Branding и стандартные scopes openid, email, profile. Если приложение находится в тестовом режиме, добавь свой адрес в Test users.
2. В Authorized redirect URIs укажи https://dntuchblnbpxgvdggapw.supabase.co/auth/v1/callback.
3. В Supabase → Authentication → Sign In / Providers → Google включи провайдера и внеси Client ID и Client Secret из Google Cloud. Секрет хранится в Supabase.
4. В Supabase → Authentication → URL Configuration → Redirect URLs добавь следующие адреса.

```
flightdeck-auth://callback
http://127.0.0.1:*/auth/**
```

Первый используется macOS, второй — одноразовым локальным приемником Windows. Для опубликованной веб-версии добавь ее точный URL отдельно. Автономный HTML, открытый через file://, поддерживает вход по email и паролю.

Для доступа к существующему журналу выбирай тот Google-аккаунт, email которого совпадает с текущим аккаунтом FlightDeck. Доступ к журналу определяется идентификатором пользователя Supabase. При проверке убедись, что после входа открыт прежний журнал.

Документация — https://supabase.com/docs/guides/auth/social-sign-in/auth-google и https://supabase.com/docs/guides/auth/redirect-urls.

## Оценка длительности

При создании рейса на компьютере укажи маршрут, борт и время вылета. Приложение показывает медиану фактической длительности завершенных перелетов этого направления. В первую очередь учитывается выбранный тип самолета. Деморейсы, отмененные рейсы и незавершенные записи исключаются.

Кнопка «Рассчитать время прилета» переносит оценку в плановое время прибытия. После этого время можно изменить вручную.

## Статистика реальных рейсов

Настольный клиент запрашивает статистику через Supabase Edge Function `route-duration`. Для запроса нужен действующий сеанс FlightDeck. Ключ Aviationstack хранится в секрете Supabase `AVIATIONSTACK_KEY`.

Для настройки добавь секрет в **Supabase → Edge Functions → Secrets**, разверни функцию `route-duration` из `supabase/functions/route-duration/index.ts` с включенной проверкой JWT и проверь расчет после входа в настольном приложении.

В плане в первую очередь используется собственная история, а статистика реальных рейсов выводится рядом для сравнения. При отсутствии собственной истории используется внешняя оценка. Выборка содержит максимум 100 доступных завершенных рейсов ответа сервиса. Медиана считается по фактическому времени отправления и прибытия. Обратное направление рассчитывается отдельно.

Ответы с наблюдениями хранятся в локальном кэше один час, пустые ответы — 10 минут. Приложение сообщает об исчерпании квоты, неподдерживаемом запросе тарифа и недоступности базы. Доступность фактических времен зависит от покрытия Aviationstack.
