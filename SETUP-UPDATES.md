# Выпуск FlightDeck для macOS и Windows

## Версии

Обычные публичные выпуски имеют формат `vMAJOR.MINOR.0`. Версии с ненулевой третьей цифрой публикуются только по отдельному запросу. Укажите один номер версии в `FlightDesk/Info.plist` и `FlightDeck-Windows/package.json`. Увеличьте `CFBundleVersion` в macOS. Этот номер определяет порядок автообновления и версию пакета Installer. Установщик macOS отклоняет замену приложения более старой сборкой, даже если публичный номер версии выше.

## Сборка на macOS

Из корня проекта выполните:

```sh
python3 FlightDesk/build-web.py
UNIVERSAL_BUILD=1 bash FlightDesk/build-mac.sh
bash FlightDesk/build-installer.sh
```

Пакет появится в `releases/`. Для Windows используйте [инструкцию сборки Windows](FlightDeck-Windows/README.md).

## Публикация

1. Добавьте раздел новой версии в [историю выпусков](CHANGELOG.md) и отправьте изменения в `main`.
2. Откройте [Release FlightDeck](https://github.com/valerii-palch/FlightDeck/actions/workflows/release.yml) и запустите **Run workflow** с новым тегом. Выпуск также можно запустить отправкой проверенного коммита в ветку `release/vMAJOR.MINOR.0`. Для отдельной публикации патча включите `publish_patch` или используйте ветку `release/patch/vMAJOR.MINOR.PATCH`.
3. Проверьте результаты сборки, подписи манифеста, контрольных сумм и тестовой установки Windows. Убедитесь, что новый выпуск отмечен как `latest`.
4. Проверьте обновление с предыдущего публичного выпуска на реальном оборудовании.

Workflow получает ключ подписи манифеста через секрет GitHub Actions `FLIGHTDECK_UPDATE_PRIVATE_KEY`. Закрытый ключ хранится вне репозитория, а открытый ключ встраивается в приложение. На macOS приложение проверяет подпись манифеста и SHA-256 пакета перед запуском системного установщика. На Windows `electron-updater` проверяет установщик по данным `latest.yml`.

FlightDeck проверяет наличие обновления при запуске и каждые 30 минут работы. Кнопка **Обновить приложение** также доступна в настройках.

Настройка входа Google, облачного журнала и статистики реальных рейсов описана в [руководстве по облачным функциям](SETUP-CLOUD.md).

## Справочник аэропортов

При первой сборке загружаются закреплённые версии OurAirports и mwgg/Airports. Сборка встраивает выбранные аэропорты и часовые пояса в HTML. База открывается без сети. Сетевые фотографии загружаются отдельно, когда доступна свободная фотография из Wikipedia. Источники и лицензия указаны в `FlightDesk/airport-data-license.txt`.
