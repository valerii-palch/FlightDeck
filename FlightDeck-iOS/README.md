# FlightDeck для iPhone

Версия 0.3.0 для iOS 17 и новее. Две вкладки: «Рейс» и «Профиль».
Мобильное приложение читает журнал Supabase, который публикует FlightDeck на компьютере.

## Запуск

1. На Mac распакуй архив и открой `FlightDeck.xcodeproj` в Xcode 16 или новее.
2. Выбери симулятор iPhone и нажми Run (⌘R). Для своего iPhone подключи устройство,
   выбери команду в Signing & Capabilities и затем выбери iPhone как устройство запуска.
   Если идентификатор приложения занят, укажи свой в Bundle Identifier.
3. Во вкладке «Профиль» войди с теми же email и паролем, что и на компьютере.
4. Если журнал еще пуст, отправь записи в облако из профиля настольного FlightDeck.
   Создавать новую таблицу для iOS не требуется.

Пока приложение открыто, журнал обновляется каждые 45 секунд и при возвращении на экран.
Можно потянуть экран рейса вниз для ручного обновления. Последняя успешная загрузка показана в UTC.
Сеанс хранится в Keychain устройства. Выход удаляет сеанс и убирает данные из приложения.

Карточка показывает рейс в работе, текущий запланированный, ближайший будущий
или последнюю запись. Для статусов «в работе» действует временное окно
от трех часов до вылета до двенадцати часов после планового прибытия.
Деморейсы по умолчанию скрыты. Включить их можно в профиле.

## Live Activity

Нажми «Следить за рейсом» под карточкой незавершенного рейса. На экране
блокировки появится маршрут, статус и плановое время прилета в UTC.
На iPhone с Dynamic Island компактный режим показывает коды аэропортов,
а долгое нажатие раскрывает статус и время. Для кодов используется IATA,
если он есть в журнале, иначе ICAO.

Следить можно за одним рейсом. Активность обновляется вместе с журналом,
пока FlightDeck открыт. После двух минут без успешного обновления карточка
отметит данные как устаревшие. Обновления через APNs пока не подключены.
При получении статуса «Выполнен» или «Отменен», выходе из аккаунта или
нажатии «Остановить слежение» активность закрывается.

Для запуска на iPhone укажи одну команду подписи для FlightDeck и
FlightDeckActivity. Если меняешь Bundle Identifier приложения, обнови
идентификатор расширения, добавив к идентификатору приложения `.activity`.

Для входа через Google нужны настройки из `../SETUP-0.19.md`. Распакуй весь комплект, сохранив соседний каталог `shared/`, который содержит общий код входа для macOS и iOS.
