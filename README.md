# FlightDeck

**Планировщик и личный журнал перелётов для macOS и Windows.** Собирайте будущие и завершённые рейсы в одном месте, смотрите маршруты на карте и возвращайтесь к истории поездок на другом компьютере.

[Скачать FlightDeck](https://github.com/valerii-palch/FlightDeck/releases/latest) · [Что нового](CHANGELOG.md) · [Сообщить о проблеме](https://github.com/valerii-palch/FlightDeck/issues/new/choose)

## Возможности

- Планирование перелётов и карточки рейсов с временем вылета и прилёта.
- Карта маршрутов, справочник аэропортов и список бортов.
- Личный журнал с синхронизацией между устройствами после входа.
- Экспорт и импорт резервной копии журнала в JSON.
- Демо с вымышленными рейсами, аэропортами и бортами. Его можно открыть без аккаунта.
- Русский и английский интерфейс.

## Установка

| Платформа | Требования | Файл |
| --- | --- | --- |
| macOS | macOS 13 или новее, Apple Silicon или Intel | `FlightDeck-macOS-*.pkg` |
| Windows | Windows 10 или 11, x64 или ARM64 | `FlightDeck-*-Windows-Setup.exe` |

Скачайте установщик для своей платформы со [страницы последнего выпуска](https://github.com/valerii-palch/FlightDeck/releases/latest). После запуска войдите в аккаунт или выберите «Продолжить без авторизации и посмотреть демо».

Публичная нумерация начинается с **0.1.0**. При переходе со старой серии 0.22–0.24 на Windows закройте FlightDeck и один раз запустите новый установщик вручную. Перед переходом можно сохранить резервную копию журнала в профиле.

## Разработка

| Компонент | Где находится |
| --- | --- |
| Общий настольный интерфейс и оболочка macOS | [FlightDesk](FlightDesk/) |
| Electron и установщик Windows | [FlightDeck-Windows](FlightDeck-Windows/) |
| Облачные функции и схема журнала | [supabase](supabase/) |

Команды сборки macOS и правила публикации описаны в [руководстве по выпуску](SETUP-UPDATES.md). Инструкции для [Windows](FlightDeck-Windows/README.md) находятся рядом с исходниками.

Публичные настольные версии имеют вид `vMAJOR.MINOR.0`. Третья цифра зарезервирована для внутренних сборок.
